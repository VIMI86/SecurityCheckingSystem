# Стек

Стек выбран так, чтобы один человек на Ubuntu закрыл пять этапов курса и мог показать каждый критерий командой, а не слайдом.

| Технология | Роль | Почему она |
| --- | --- | --- |
| Ubuntu на ноутбуке | Среда разработки и хост контейнеров | Уже установлена. Подходит для Docker и сетевых экспериментов этапа 4. |
| Python и FastAPI | API и сервисы | Быстрый каркас, OpenAPI для демонстрации без отдельного UI, удобные тесты и схемы входа агентов. |
| Docker Compose | Запуск стека | Одна команда поднимает учебную систему. Kubernetes курс на этом MVP не требует. |
| PostgreSQL | Основная БД | Транзакции, SQL, CRUD, репликация, backup и restore — прямые критерии этапов 3 и 5. |
| Redis | Кэш | Короткий показ read/write, TTL и cache-aside для статуса задачи. |
| RabbitMQ | Брокер | Очереди, producer, consumer, ack и учебная отказоустойчивость quorum queues. |
| pytest и httpx | Проверки | Модульные и интеграционные тесты потока задачи и трёх решений политики. |
| Адаптер LLM | Вызов модели | Один интерфейс, два провайдера: `mock` и `ollama`. |
| nftables | Фильтрация | Разрешающие и запрещающие правила на хосте. Сама Docker-сеть firewall не заменяет. |

LangGraph в первый контур не входит. Состояние workflow ведёт Orchestrator. Политику он не принимает: решение остаётся у Policy Service.

## Адаптер LLM

Провайдер выбирается переменной окружения `LLM_PROVIDER`.

- `mock` — фиксированные ответы для тестов и защиты, когда homelab выключен. Инфраструктурные сценарии зависят только от этого режима.
- `ollama` — HTTP к Ollama на homelab. Базовый URL и имя модели задаются `OLLAMA_BASE_URL` и `OLLAMA_MODEL`. Значения в репозиторий не коммитятся, пока они не станут публичными для лаборатории. Секретов у локальной Ollama обычно нет; адрес домашней сети всё равно остаётся в `.env`.

Адаптер лежит в `services/agent/app/llm.py`. Вход и выход заданы схемами, событие больше 64 КиБ отклоняется, вызов Ollama ограничен таймаутом. `mock` возвращает фиксированный разбор и не открывает сеть. `ollama` ходит на `OLLAMA_BASE_URL` к модели `OLLAMA_MODEL`. Ошибка модели отдаёт агенту 503, и задача переходит в ошибку после повторной доставки.

## Что сознательно отложено

Отдельный frontend не делается: курс закрывается Swagger/OpenAPI и curl. Kubernetes, service mesh и промышленный кластер не дают новых обязательных демонстраций и усложняют firewall и failover. Своя модель не обучается: курс проверяет инфраструктуру и контролируемый вызов уже существующей Ollama.
