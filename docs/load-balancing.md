# Балансировка нагрузки

Отчёт по шестому заданию. Проверено на ноутбуке 16 ноября 2026.

## Что требовалось

Несколько экземпляров для обработки запросов, HAProxy между ними и проведённое нагрузочное тестирование.

## Что изменилось

Три экземпляра API принимают одну и ту же работу: `api`, `api-2` и `api-3`. В ответах они представляются как `api-1`, `api-2` и `api-3`. У каждого свои сети к PostgreSQL, Redis и RabbitMQ. Состояние по-прежнему общее: база, кэш и очередь не размножались.

HAProxy слушает `127.0.0.1:8000` и `127.0.0.1:8404`. Порт `8000` больше не опубликован у самих экземпляров API. Клиент, страница `/ui` и прежние команды `curl` попадают в балансировщик. Он раздаёт запросы по кругу и снимает экземпляр, если `GET /health` перестаёт отвечать `200`. В ответ добавляется заголовок `X-Sentinel-Backend` с именем экземпляра. Страница статистики: `http://127.0.0.1:8404/stats`.

Конфигурация лежит в `deploy/haproxy/haproxy.cfg`. Нагрузочный клиент — `scripts/load_test.py`. Firewall разрешает всем трём экземплярам API соединения к PostgreSQL, Redis и RabbitMQ. Orchestrator и Agent остаются в одном экземпляре: они не принимают пользовательские запросы.

## Проверка готовности

Девять последовательных `GET /ready` через HAProxy вернули `200`. Среди них были `api-1`, `api-2` и `api-3`, то есть каждый экземпляр видит базу, кэш и брокер.

## Нагрузочный прогон

Команда:

```bash
python3 scripts/load_test.py --requests 300 --concurrency 15
```

Цель — `GET http://127.0.0.1:8000/health`. Это вход API, без постановки задачи и без вызова Ollama.

| Показатель | Значение |
| --- | --- |
| Запросы | 300 |
| Параллельность | 15 |
| Ошибки | 0 |
| Коды ответа | 200 × 300 |
| Время прогона | 0,223 с |
| Пропускная способность | 1342 запроса/с |
| Задержка min / avg / p95 / max | 2,9 / 10,8 / 19,2 / 27,1 мс |
| `api-1` | 100 |
| `api-2` | 100 |
| `api-3` | 100 |

Заголовок `X-Sentinel-Backend` и поле `service` в теле ответа совпали. Круговая раздача разложила 300 запросов на три экземпляра поровну.

Повторить прогон:

```bash
python3 scripts/load_test.py --url http://127.0.0.1:8000/health --requests 300 --concurrency 15
```
